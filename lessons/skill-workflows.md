# Lessons behind the workflows

The skills keep their operating instructions separate from the reasons those
instructions changed. This record preserves the earlier design lessons without
requiring an agent to read them for every invocation.

## Ground the task before changing its direction

Earlier versions described research and criticism that missed decisions already
recorded in a project. The shared correction is to read the relevant project state
and carry its constraints into the analysis. Repeating that state verbatim in chat
does not prove the reasoning used it, so the operating instructions require the
context without a mandatory quotation ritual.

## A useful critique needs a check

A plausible objection can sound convincing while remaining untested. Red Team
retains a failure mechanism and a concrete disproof step. Prove separates confirmed,
wrong, and unverified claims. Direct language should make those distinctions clear,
not turn an adversarial hypothesis into a certainty.

## Separate planning from authorization

Breakdown previously offered to start work while also saying it would not execute
until the user chose. It now gives a plan and next action without that contradiction.
Research or criticism can identify a repair, but a review request does not itself
authorize changing the artifact. Existing authorization for the underlying work
still applies.

## Interview for decisions, not a count

Grill Me uses the brief already available and asks questions that change the result.
A fixed count can create padding or repeat settled choices. The spec remains the
record of the agreed work; an explicit instruction to proceed does not need another
approval question.

## Parallel frames have limits

Fanout keeps five perspectives and one critic. Earlier instructions advertised a
fixed token multiplier and a general performance advantage without providing the
measurement conditions. The current skill describes the extra work and leaves its
cost and benefit dependent on the task. Agreement across frames is a signal to
inspect, not independent proof. Sequential frames in one conversation do not become
independent agents merely by receiving separate headings.
