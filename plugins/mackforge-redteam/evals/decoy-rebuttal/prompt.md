Stress-test this conclusion before I put it in the quarterly review.

Our app's March release added a dark mode toggle. Average session length rose 18% in March compared with February, so dark mode is making people use the app longer.

Context: the same February-to-March comparison last year moved session length by less than 1%. Only 9% of users have turned dark mode on, and session length rose by roughly the same 18% for users who never enabled it. The March release also raised the inactivity timeout that ends a session in our analytics from 15 minutes to 30 minutes.
