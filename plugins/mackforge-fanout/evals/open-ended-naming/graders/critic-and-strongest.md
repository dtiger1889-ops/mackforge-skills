Pass only if the response contains an assessment of the ideas beyond listing them, with all of:

1. A prioritisation: a small number of strongest directions (about three, or fewer), with a reason each ranks where it does. Explicit numeric scores are not required.
2. Some grouping of equivalent ideas or a note on where the frames converged.
3. For the strongest directions, a riskiest assumption and a concrete test or first step.
4. A single synthesized strongest direction, plus what evidence is still needed.

Fail if any of the four is missing, or if the response is only an unranked list of ideas.
